# Use-case сценарий для слайдера Slick

На главной странице с помощью карусели отображаются 
текущие акции. 
Пользователь может просматривать изображения акций, 
меняющиеся автоматически через заданный интервал.

## Сценарий использования

- При загрузке страницы инициализируется слайдер с изображениями текущих акций.
- Слайды автоматически сменяются каждые 2 секунды.
- Под слайдером отображаются точки-индикаторы, которые показывают текущий слайд и общее количество акций.
